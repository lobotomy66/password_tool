# SafeBox — менеджер паролей

Учебный проект, вдохновлённый KeePassXC: локальное зашифрованное хранилище
паролей с единым мастер-паролем.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

При первом запуске приложение попросит создать мастер-пароль —
он защищает всё хранилище и нигде не сохраняется в открытом виде.

## Структура проекта

| Файл           | Назначение                                              |
|----------------|----------------------------------------------------------|
| `main.py`      | Интерфейс (CustomTkinter): экраны входа и работы с записями |
| `security.py`  | Криптография: хеширование мастер-пароля (Argon2), шифрование данных (Fernet/AES) |
| `database.py`  | Хранение в SQLite (`vault.db`)                          |
| `generator.py` | Генератор случайных паролей и оценка их сложности       |

## Как это защищено 

1. **Мастер-пароль не хранится.** Хранится только его Argon2-хеш —
   восстановить из него исходный пароль практически невозможно.
2. **Ключ шифрования не хранится вообще.** Он каждый раз заново
   вычисляется из мастер-пароля и случайной соли через PBKDF2-HMAC-SHA256
   (390 000 итераций — рекомендация OWASP). Поэтому даже если файл `vault.db`
   украдут, без мастер-пароля данные бесполезны.
3. **Сами записи (логин/пароль/заметки) хранятся зашифрованными** алгоритмом
   Fernet (AES-128-CBC + HMAC для проверки целостности — нельзя незаметно
   подменить зашифрованные данные).
4. **Генератор паролей** использует модуль `secrets`, а не `random` —
   `random` предсказуем и не годится для криптографии.



## Возможные доработки

- Автоблокировка хранилища через N минут бездействия
- Экспорт/импорт в зашифрованный файл
- История изменений паролей
- Проверка паролей на утечки (Have I Been Pwned API)
